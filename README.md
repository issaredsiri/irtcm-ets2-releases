# Truck Dash: คู่มือสำหรับเพื่อน

แดชบอร์ด + แมพ ETS2 บนมือถือ เห็นรถเพื่อนในห้องเดียวกัน และใช้เส้นทางร่วมจาก waypoint ในเกม

## ต้องมี

- Windows 10/11 64-bit + Euro Truck Simulator 2 (Steam)
- มือถือต่อ Wi-Fi วงเดียวกับ PC
- **Room code** จากเจ้าของห้อง (หน้าตาแบบ `ABCD-EFGH-JKLM`)

## ติดตั้ง (ครั้งเดียว)

1. ดับเบิลคลิก **`TruckDash-Setup-v*.exe`**
   - ถ้า Windows ขึ้น "Windows protected your PC" → กด **More info** → **Run anyway** (โปรแกรมไม่ได้ซื้อ certificate)
   - ติดตั้งลง `%LOCALAPPDATA%\TruckDash` ไม่ต้องใช้สิทธิ์ admin · สร้าง shortcut **Truck Dash** บน Desktop + Start Menu
2. Setup จะเปิด **Truck Dash** ให้เองเมื่อติดตั้งเสร็จ
3. ครั้งแรกโปรแกรม Ets2Telemetry จะขอติดตั้ง plugin ลงเกม → กดยืนยัน (ขอสิทธิ์ admin)
4. หน้าต่างดำจะถาม:
   - **ชื่อที่เพื่อนเห็น** เช่น `Bee`
   - **Room code** → ใส่ code ที่ได้มา (ถ้าเว้นว่าง = สร้างห้องใหม่ของตัวเอง)
5. ถ้า Windows Firewall ถามเรื่อง `node.exe` / `Ets2Telemetry` → อนุญาต **Private networks**
6. เบราว์เซอร์จะเปิดหน้า QR code → **สแกนด้วยมือถือ** (เก็บเป็น bookmark หรือ Add to Home Screen ไว้ได้)

## ใช้งานทุกครั้ง

1. เปิด **Truck Dash** จาก Desktop (ก่อนหรือหลังเปิดเกมก็ได้)
2. เปิดหน้า dashboard บนมือถือ
3. ในเกม: ปัก waypoint บนแมพ GPS แล้วกด **F5** (Quick save) → แมพบนมือถือจะอัปเดตเส้นทาง
   - แมพเห็นเส้นทางใหม่เฉพาะตอนเกมเซฟ (F5 หรือ autosave)
   - ถ้าแมพขึ้นว่า "เส้นทางในเกมไม่ตรงกับแมพ" ให้กด F5 อีกที

บนแมพ:
- **เส้นสีน้ำเงิน** = เส้นทางของกลุ่ม (ของคนที่กด F5 ล่าสุด, มี ★ ข้างชื่อ)
- **เส้นสีอื่น** = เพื่อนที่ใช้เส้นทางต่างจากกลุ่ม (มี ⑂ ข้างชื่อ)
- แตะชื่อเพื่อนในแถบล่าง = กล้องไปดูเพื่อน · แตะ "กลับตำแหน่งรถ" = กลับมาที่รถเรา

## อัปเดต

อัตโนมัติ: ทุกครั้งที่เปิด **Truck Dash** จะเช็คเวอร์ชันใหม่จาก GitHub และอัปเดตให้เองก่อนเริ่ม
(ไม่มีเน็ตก็เปิดได้ปกติ ใช้เวอร์ชันเดิม) · ถ้าได้ Setup เวอร์ชันใหม่มา รันทับได้เลย ชื่อ/ห้องเดิมยังอยู่

## เปลี่ยนชื่อ / เปลี่ยนห้อง

ลบไฟล์ `%LOCALAPPDATA%\TruckDash\tools\bridge.config.json` แล้วเปิด **Truck Dash** ใหม่ จะถามชื่อ + room code อีกครั้ง

## แก้ปัญหา

| อาการ | ลองทำ |
|---|---|
| มือถือเปิดหน้าไม่ได้ | มือถือกับ PC ต้องอยู่ Wi-Fi เดียวกัน · อนุญาต Firewall (Private) · ลอง IP อื่นในหน้า QR |
| ขึ้น "Waiting for game…" | เปิดเกมแล้วขับออกจากเมนู · ถ้ายังไม่ขึ้น ให้ติดตั้ง plugin ใหม่จากหน้าต่าง Ets2Telemetry |
| ไม่เห็นเพื่อน | ดูหน้าต่าง **Truck Dash bridge** (ย่ออยู่ใน taskbar) ต้องขึ้น "เกม: ต่อแล้ว" และ "ส่งแล้ว" เพิ่มขึ้นเรื่อยๆ · room code ต้องตรงกันทุกคน |
| แมพไม่มีเส้นทาง | ปัก waypoint ในเกมแล้วกด F5 · หน้าต่าง **Truck Dash route server** ต้องเปิดอยู่ |
